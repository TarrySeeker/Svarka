# Настройка уведомлений для проекта Svarка

## Что реализовано

✅ **Калькулятор услуг** - пользователи могут рассчитать стоимость сварочных работ
✅ **Корзина** - добавление товаров и услуг с возможностью указания контактов
✅ **Система заявок** - сохранение заказов в БД с полной информацией
✅ **Уведомления в Telegram** - отправка заявок в Telegram-бот
✅ **Уведомления на email** - отправка на почту владельца бизнеса
✅ **Интеграция с ЮКасса** - обработка платежей (опционально)

## Настройка Telegram-бота

1. Создайте бота через [@BotFather](https://t.me/BotFather)
2. Получите токен бота 
3. Найдите Chat ID (можете отправить сообщение боту и посмотреть через API)
4. Добавьте в `.env`:
   ```
   TELEGRAM_BOT_TOKEN=your_bot_token_here
   TELEGRAM_CHAT_ID=your_chat_id_here
   ```

### Как получить Chat ID:

1. Отправьте сообщение вашему боту
2. Перейдите по ссылке: `https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates`
3. Найдите `"chat":{"id":12345678}` в ответе

## Настройка Email уведомлений

### Вариант 1: SendGrid
```bash
EMAIL_SERVICE_URL=https://api.sendgrid.v3/mail/send
EMAIL_SERVICE_TOKEN=your_sendgrid_api_key
BUSINESS_EMAIL=admin@24svarkaekb.ru
```

### Вариант 2: Другой email-сервис
Измените `formatEmailMessage` и URL в файле `/app/api/notifications/route.ts`

## База данных

Выполните SQL из `schema.sql` для создания всех необходимых таблиц:
- `services` - каталог услуг
- `calculator_settings` - настройки калькулятора 
- `orders` - заявки клиентов

## Проверка работы

1. Перейдите на `/calculator`
2. Сделайте расчет и добавьте в корзину
3. Заполните форму в `/cart` 
4. После отправки заявка должна прийти в Telegram и на почту

## Структура заявки

В админку, Telegram и на почту приходит полная информация:
- Имя и телефон клиента
- Комментарий (если есть)
- Список услуг/товаров с ценами
- Информация о доставке (если выбрана)
- Общая сумма заказа

## Дополнительные возможности

- Товары можно добавлять в корзину (уже реализовано)
- Расчет доставки СДЭК (уже интегрирован)
- Оплата через ЮКасса (опционально)
- Настраиваемые тарифы калькулятора через админку

## Что НЕ реализовано (может понадобиться)

- Админка для просмотра заявок
- SMS-уведомления 
- Автоответ клиенту на email
- Интеграция с CRM-системами
